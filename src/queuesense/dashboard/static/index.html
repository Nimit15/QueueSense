How It Works

Three core innovations that make QueueSense outperform every baseline in mixed Indian traffic conditions.

Density-Based Green Extension

Real-time queue pressure detection extends green for platoons until the lane clears, then switches early.

Preemptive Downstream Gating

QueueSense reads downstream exit occupancy and holds upstream green red to prevent intersection gridlock.

Downstream-Flush Priority

Emergency vehicles trigger downstream junction green waves first, clearing the corridor ahead.
